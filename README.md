# CNC Roraima — Portal Cristhian Cruz News

Portal de notícias com identidade visual em vermelho, dourado e grafite. Construído com Next.js, React e TypeScript.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Estado atual

A primeira versão implementa a homepage responsiva com manchete principal, editorias, últimas notícias e destaque institucional da CNC. Os textos e cartões são conteúdo demonstrativo; ainda não representam notícias verificadas nem estão conectados a um CMS.
